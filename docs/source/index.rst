AiiDAlab DL_POLY Documentation
==============================

Welcome to the AiiDAlab DL_POLY application documentation. This application
provides a wizard-style interface for configuring, submitting and inspecting
DL_POLY molecular dynamics simulations within the AiiDA/AiiDAlab environment.
It builds on the `aiida-dlpoly <https://github.com/stfc/aiida-dlpoly>`_ plugin
which provides the underlying AiiDA calculation and parser.
